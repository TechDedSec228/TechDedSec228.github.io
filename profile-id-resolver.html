Як користуватись

Букмарклет працює прямо у твоєму браузері — без серверів, логів і сторонніх запитів.

1. Додай букмарклет
Перетягни Profile ID Resolver у панель закладок (або клацни правою кнопкою і збережи як закладку).
2. Відкрий сторінку профілю
Перейди на профіль у Instagram, Threads, X, YouTube, TikTok, Facebook, VK чи OK.
3. Натисни на закладку
З’явиться невелике вікно з ID, username, джерелом даних і зручними URL. Є кнопки «Copy JSON», «Copy ID», «Copy URL».
4. Онови сторінку, я хз
Буває, що сайт залипає і в html зберігаються залишки попередніх пройдених сторінок. Онови сторінку, щоб підвантажити актуальні її ідентифікатори, тоді букмарклет точно покаже дійсні дані.

Threads Profile API (необов’язково)

Для Threads поки немає публічного URL, який напряму будується з ID, але через GET‑запит до API можна отримувати актуальний username, маючи ID. Якщо в тебе є token, букмарклет додатково покаже поле URL2 з готовим API‑запитом, яке ти зможеш зберегти. Якщо токена немає, це поле приховане, щоб не перевантажувати інтерфейс.

Як отримати такий токен — дивись інструкцію отута .

Введи свій токен у полі нижче — він автоматично підтягнеться в букмарклет, після чого просто перетягни посилання в закладки. Усі обчислення виконуються локально в твоєму браузері, ця сторінка — лише зручний UI для генерації закладки.

Токен з Threads Profile API. Зберігається лише в твоєму браузері, нікуди не відправляється. Використовується тільки для формування URL2 усередині букмарклета.

Букмарклет з токеном

Після введення токена посилання букмарклета автоматично оновиться. Перетягни його в панель закладок — токен буде вбудований тільки у твою локальну копію.

Якщо токен не заданий, у Threads буде тільки URL профілю з нікнеймом. При наявності токена з’явиться окреме поле URL2 і кнопка Copy URL2.

Працює локально, без аналітики та сторонніх запитів. Зручно для OSINT, тестування інтеграцій та ручного реверсу.
