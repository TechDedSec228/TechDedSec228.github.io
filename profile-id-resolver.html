Букмарклет для профілів соцмереж

Швидко показує ID профілю та корисні дані прямо на відкритій сторінці.

Цей букмарклет допомагає за кілька секунд подивитися основний ідентифікатор профілю, username, посилання на сторінку та звідки взято результат. Підійде, коли треба швидко перевірити профіль без зайвих сервісів і вкладок.

Що він вміє

Тут зібрано лише функціонал простими словами — без технічного опису того, як саме це працює.

Показує ID профілю

Дістає головний ідентифікатор профілю або сторінки, якщо він доступний на відкритій вкладці.

Показує username

Підтягує нік або коротке ім’я профілю, якщо воно є на сторінці чи в її посиланні.

Пояснює джерело результату

Показує, звідки саме взято знайдені дані, щоб було легше зрозуміти, наскільки результат доречний.

Копіює дані в буфер

Дозволяє окремо скопіювати ID або одразу весь результат у зручному форматі.

Працює на популярних платформах

Розрахований на профілі в Instagram, Threads, X, YouTube, TikTok, Facebook, VK та OK.

Дає результат одразу на сторінці

Після запуску відкриває компактну картку поверх сайту, щоб не треба було переходити кудись ще.

Встановлення

1

Увімкни панель закладок

Якщо вона прихована, покажи її в браузері, щоб було куди перетягнути кнопку.

2

Перетягни кнопку

Затисни кнопку «Profile ID Resolver» і перетягни її прямо в закладки.

3

Відкрий потрібний профіль

Зайди на сторінку профілю або каналу в підтримуваній соцмережі й натисни збережену закладку.

Використання

Після запуску букмарклет показує компактну картку поверх відкритої сторінки. Усе зібрано так, щоб дані можна було швидко переглянути та одразу скопіювати.

Що побачиш після запуску

  • ID профілю або сторінки.
  • Username, якщо він доступний.
  • Поточне посилання на профіль.
  • Позначку джерела для знайденого результату.

Що можна зробити далі

  • Скопіювати тільки ID.
  • Скопіювати весь результат одним блоком.
  • Закрити картку й продовжити роботу зі сторінкою.
  • Швидко перевірити інший профіль без перевстановлення.
